# Guia do piloto Punho

Estado atual: demonstração local. Os dados não sincronizam entre dispositivos.

1. Inicie a app no Windows com `flutter run -d windows`.
2. Conclua o onboarding com uma empresa de aluguer, 15 máquinas e dois colaboradores.
3. Registe máquinas, clientes, leads, reservas, despesas e recebimentos.
4. Confirme que o dashboard usa “resultado operacional simples”, nunca lucro.

Para restaurar a demonstração, feche e volte a iniciar a app: a persistência atual é em memória.

Não utilizar com dados reais até Supabase, RLS, autenticação e sincronização estarem concluídos.
