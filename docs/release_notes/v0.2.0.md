# v0.2.0 — sincronização deixa de precisar de botão, e um cartão novo para prever o mês

## Novo

**Cartão "Previsão do mês"**, em Empresa › Finanças. Complementa o "Encontro
de contas" (que só mostra o que já aconteceu) com uma previsão de como o mês
deve fechar: entradas previstas somam o que já entrou com o que está por
receber nas reservas já marcadas para este mês (nunca inventa clientes
novos); saídas previstas somam os custos fixos declarados com a média das
despesas variáveis do mês passado e do mesmo mês do ano anterior.

## Correcções

**Custos fixos e dados da empresa deixam de depender de um botão manual de
sincronização.** Editar uma rubrica de custo fixo, ou qualquer outro dado da
empresa, sobe sozinho para o servidor assim que se grava — confirmado neste
lançamento a criar uma rubrica de raiz e a ver a alteração chegar à Supabase
sem tocar em nada mais.

## Por dentro

Infra-estrutura inicial (inerte, sem ecrã nem efeito visível ainda) para
detectar e assinalar conflitos de reserva quando dois colaboradores, ambos
offline, reservam a mesma máquina para clientes diferentes — a decisão
continua sempre a cargo do Gestor, nunca automática.

O workflow antigo do GitHub Actions, que compilava e publicava releases sem
passar pelo i9, foi removido — só o processo i9-first publica a partir de
agora.

## Testes

`flutter analyze` limpo, suite completa a passar. Testado no telemóvel:
reinstalação do zero, sessão iniciada de novo, sincronização trouxe de volta
todos os dados da empresa sem acção manual, cartão de previsão a recalcular
ao vivo ao gravar uma rubrica nova.
