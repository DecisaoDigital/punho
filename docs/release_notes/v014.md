# v0.0.14 — sincronização de empresa com o Control

Bug estrutural: até esta versão, os dados do onboarding (NIF, morada, telefone, facturação, custos) ficavam **só no telemóvel**. Nada subia ao Supabase, portanto o Control nunca via a empresa na sua lista.

## Fixes
- **DB migration:** nova coluna `punho_empresas.dados` (jsonb) + trigger `punho_empresas_sync_licenca` que cria/actualiza automaticamente a linha em `licencas` (app='punho') sempre que o payload contém NIF válido — é o que o Control lê.
- **Edge Function `sincronizar-empresa-punho`:** verifica que o utilizador é gestor activo em `punho_membros`, faz merge com dados existentes, grava em `punho_empresas.dados`.
- **App:** novo `EmpresaSyncService`. Ao **Guardar** em Definições da Empresa dispara sync em background (fire-and-forget). Botão explícito **"Sincronizar com o Control"** para contas antigas que já preencheram o onboarding antes desta versão.

## Como usar (contas antigas)
Ir a Empresa → Dados → carregar em **"Sincronizar com o Control"**. Alguns segundos depois a empresa aparece na lista do Control.
