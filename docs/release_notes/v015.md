## Launcher icon + splash nativo — pipeline profissional

Substituído o remendo anterior (redimensionar PNG à mão) pela via correcta:

- **`flutter_launcher_icons`** gera: legacy PNGs (mipmap-*) + **adaptive icons Android 8+** (foreground/background separados) + **themed icon Android 13+** (monochrome que respeita cor do tema) + iOS icons

## Cadeado local (biometria + PIN) — task #201 + pedido "bloquear após inactividade"

Sprint completo:

- **`local_auth ^2.3.0`** + **`flutter_secure_storage ^9.2.4`** + **`crypto`** — biometria Android (impressão digital / rosto) + PIN cifrado no Keystore
- `MainActivity.kt` passa a **`FlutterFragmentActivity`** (requisito do `local_auth` para o `BiometricPrompt`)
- Permissão `USE_BIOMETRIC` (+ legacy `USE_FINGERPRINT`) no `AndroidManifest.xml`
- Módulo `lib/core/cadeado/`:
  - `cadeado_service.dart` — PIN (sha256+salt), threshold em minutos, biometria, timestamps
  - `lock_screen.dart` — ecrã de bloqueio com símbolo Punho, dispara biometria automaticamente, PIN como fallback, após 5 tentativas falhadas oferece terminar sessão
  - `cadeado_gate.dart` — `WidgetsBindingObserver` que activa bloqueio quando `resumed - paused > threshold`
  - `definicoes_cadeado_page.dart` — definir/mudar PIN, threshold (Nunca/1/5/15/30 min), toggle biometria, "Bloquear agora" para testar
- Wiring: `PunhoApp` envolve destino com `CadeadoGate`. Cold start bloqueia se PIN definido.
- Entrada "Cadeado (PIN + biometria)" adicionada ao popup de Perfil.

**Fluxo:** ao definir PIN pela 1ª vez, o cadeado passa a activar (cold start + após 5 min de inactividade por defeito). Threshold é ajustável nas Definições > Cadeado.
