## Como funciona
- Widget `SplashPunho` em `lib/shared/widgets/splash_punho.dart`
- Envolvido no `PunhoApp` — mostra splash à primeira montagem, depois `setState` transita para AuthGate/AppShell.

## Launcher icon + splash nativo — pipeline profissional

Substituído o remendo anterior (redimensionar PNG à mão) pela via correcta:

- **`flutter_launcher_icons`** gera: legacy PNGs (mipmap-*) + **adaptive icons Android 8+** (foreground/background separados) + **themed icon Android 13+** (monochrome que respeita cor do tema) + iOS icons
- **`flutter_native_splash`** gera: splash nativo Android (aparece nos ~300ms antes do Flutter arrancar) + splash Android 12+ API + dark mode
- **Integrado no `release.yml`**: cada build no CI corre `dart run flutter_launcher_icons` + `dart run flutter_native_splash:create` antes do `flutter build apk`. Nunca fica dessincronizado. Source-of-truth em `assets/brand/`.

3 novas variantes do símbolo em `assets/brand/`:
- `ic_launcher_foreground.png` — símbolo sem fundo, com padding interior de 34% (adaptive icon)
- `ic_launcher_monochrome.png` — silhueta branca para themed/notification
- `splash_symbol.png` — símbolo grande centrado para splash nativo
